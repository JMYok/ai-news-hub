### Yann LeCun (Meta AI Chief Scientist, Turing Award Winner, AMI Labs Founder)

LeCun 在这期 Unsupervised Learning 播客中分享了他离开 Meta 创立 AMI Labs 的原因。他直言不讳地表示：LLM 在语言操纵上表现出色，但这不是通往人类级甚至动物级智能的路径。真正的智能系统需要能够预测行动后果并进行规划——这正是 JEPA（联合嵌入预测架构）的核心。他的核心观点："LLM 本质上是不安全的，因为你无法阻止它们产生幻觉，而且它们无法预测自己行动的后果。" 他预测到 2027 年初，整个行业会意识到这个范式需要改变。JEPA 的目标是学习在抽象表征空间中预测，而非在像素级别预测，这更接近人类和动物理解世界的方式。

Yann LeCun, Meta's Chief AI Scientist and Turing Award winner, left Meta to found AMI Labs with a contrarian bet against the LLM paradigm. In this episode of Unsupervised Learning, he explains why LLMs, while excellent at language manipulation, are not a path toward human-level or even animal-level intelligence. Real intelligent systems need to predict the consequences of their actions and plan — the core thesis of JEPA (Joint Embedding Predictive Architecture). His sharp takeaway: "LLMs are intrinsically unsafe because you cannot stop them from hallucinating and they cannot predict the consequences of their actions." He predicts that by early 2027, the entire industry will realize the paradigm needs to change. JEPA aims to predict in abstract representation space rather than pixel space, which is how humans and animals understand the world.

### Nikunj Kothari (Partner @ FPV Ventures)

Kothari 分享了一个实操技巧：通过 Claude Code 反向工程 API 来自动化任务。关键思路：很多网站无法通过 DOM 或截图"确定性"导航，所以让 Claude Code 使用 browser_harness 配合 Playwright 抓取网络请求，然后分析 API 结构、认证方式和速率限制。他预测：**"每个网站很快都需要 headless 模式，我们将需要工具.txt 让 agent 确定存在哪些工具可以被利用。"**

Nikunj Kothari, a partner at FPV Ventures, shares a practical technique: using Claude Code to reverse engineer APIs for task automation. His key insight: many websites are impossible to navigate deterministically via the DOM or screenshots, so he points Claude Code to use browser_harness by browser_use (or vanilla Playwright) to sniff network requests, then analyzes the API structure, authentication, and rate limits. He predicts: "Every website will soon need to be headless, and we'll need tools.txt for agents to determine what tools exist that can be leveraged."

### Unsupervised Learning — "Ep 86: Yann LeCun on Leaving Meta, Breaking The LLM Paradigm, & Why Hinton is Wrong"

**核心洞察：**

1. **LLM 的根本局限**：LLM 只能在 token 空间中进行自回归预测，无法真正预测行动后果、无法进行规划推理。这不是通往人类级智能的路径。

2. **JEPA 的革命性**：在学习表征空间而非像素级别进行预测，更接近人类理解世界的方式。VLA（视觉-语言-动作）模型已被行业认定为一个失败方向。

3. **为什么离开 Meta**：公司全面转向 LLM 他的世界模型研究方向得不到支持，且大多数应用场景（制造业、工业等）与 Meta 核心业务无关。

4. **AI 的安全问题**：他认为当前 LLM 本质上不安全，因为无法防止幻觉、无法保证可靠的行为。而他提出的目标驱动 AI（objective-driven AI）可以通过内置约束来保证安全。

5. **时间表**：5 年内 JEPA 将实现"全面世界统治"——他以 Linus Torvalds 的 Linux 引用来形容这个玩笑式的目标，但暗示这确实是 AI 系统的未来蓝图。
