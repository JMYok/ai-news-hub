**AI cost stratification is widening — and enterprises need new finance teams to manage it.**

Box CEO Aaron Levie cut through the noise on AI economics:

The shift happened: from AI chat tools (cheap, small context) → AI agents (giant context, longer work, 10x inference cost). The compounding happened faster than most realized.

### Anthropic Engineering: Claude Code Auto Mode

**A safer way to skip permissions.**

Anthropic introduced auto mode for Claude Code — a middle ground between manual review and --dangerously-skip-permissions. It uses model-based classifiers to catch dangerous actions that aren't aligned with user intent, while letting routine work run without prompts.

Two layers of defense:
- Input layer: server-side probe scans tool outputs for prompt injection attempts
- Output layer: transcript classifier evaluates each action before execution

Key findings from evaluation:
- Stage 1 (fast filter): 8.5% FPR, 6.6% FNR on real overeager actions
- Full pipeline: 0.4% FPR, 17% FNR

The 17% false-negative rate is honest — comparing against --dangerously-skip-permissions it's substantial improvement; comparing against careful manual review it's a regression. Auto mode targets the first group.

**Anthropic Engineering 发布了 Claude Code 的自动模式——一种更安全的权限跳过方式。** 核心思路是用分类器catch危险行为，同时让常规工作无提示运行。评估显示完整流程FPR降至0.4%，但FNR为17%。官方诚实表示：如果你在跑危险命令，这是大改进；如果你在仔细人工审核，这是一个退步。

### The MAD Podcast: OpenAI's Yann Dubois — Why AI Progress Suddenly Feels Real

**The Takeaway:** The reliability threshold is crossed. What changed is that RL moved from verifiable rewards (math competitions) to optimizing real-world utility — and this is why coding and cybersecurity are exploding right now.

Yann Dubois, co-leading OpenAI's Post-Training Frontiers team, explained the step function we're living through:

1. **Reliability threshold crossed** — December 2025, models became trustworthy for real work, not just demo purposes
2. **Self-acceleration** — Good models build the tooling to train better models, compounding the acceleration
3. **RL for real utility** — o1/o3 were optimized for verifiable rewards; GPT-5.5 extends this to messy real-world tasks
4. **Efficiency is horizontal** — Larger models actually think fewer tokens (expertise encoded in weights), and can be parallelized better at inference

On continual learning: still unsolved three years after ChatGPT. Models start higher than new employees at day zero but don't improve over time like humans do. We're still figuring out how to make the utility curve monotonically increasing.

**MAD Podcast 中，OpenAI 的 Yann Dubois 解释了为何 AI 进步现在让人感觉像是一个阶跃函数：可靠性门槛在去年12月被跨越，RL从"可验证奖励"扩展到真实世界效用优化，这就是编程和网络安全现在爆发的原因。** 他还提到持续学习仍是未解难题——模型在第零天比新员工起点高，但不会像人类一样随时间改进。
