### Maxim Bar Kogan (Co-Founder & CEO, Onyx Security) — No Priors Podcast

Onyx Security 做的是"AI 监控 AI Agent"——当企业大规模部署 Autonomous Coding Agent 时，传统安全工具（身份管理、端点安全、API 网关）全部失效，因为它们无法理解 Agent 的意图。Onyx 的核心架构：用极小的专用模型（几乎只能做一件事——判断"这里是否需要更聪明的 Agent 来审查"）作为守门人，只在真正有风险时才唤起强大但昂贵的大模型。这像极了象棋大师的直觉——大部分时候靠直觉快速判断，只有在关键局面才停下来精密推演。Maxim 的判断：Agent 失控事故（误删数据库、意外发布代码和 Token）正在爆发，而 Mythos 级别模型出现后，漏洞挖掘成本将断崖式下跌，企业必须在"Mythos 来之前"把基础安全控制建好。

Maxim Bar Kogan, co-founder and CEO of Onyx Security, joined No Priors to explain why traditional security tools — identity management, endpoint security, API gateways — are all failing as enterprises deploy autonomous coding agents at scale. These tools can't understand an AI's intent, leaving enterprises defenseless against agent actions that accidentally delete databases or expose tokens and code. Onyx's core architecture: ultra-small specialist models (barely capable of anything except deciding "does this action need a smarter agent to review it?") as gatekeepers, only invoking powerful but expensive LLMs when real risk is detected. This mirrors how chess grandmasters operate — intuition handles most moves, but they stop and calculate deeply only at critical junctures. Maxim's bottom line: agent失控 accidents are exploding, and once Mythos-level models arrive, vulnerability discovery will become so cheap that enterprises must build foundational AI security controls before Mythos ships.
