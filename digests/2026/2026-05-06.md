### Anthropic Engineering: "Claude Code auto mode: a safer way to skip permissions"

**English:**
Claude Code's new auto mode addresses a core tension: agents that are too eager to help can delete branches, expose credentials, or touch production databases. The solution is a two-layer defense. The input layer uses a prompt-injection probe that scans tool outputs before they enter the context, flagging suspicious content with a warning. The output layer uses a transcript classifier (powered by Sonnet 4.6) that evaluates each action against block rules before execution. On internal testing: final FPR is 0.4%, blocking 83% of overeager behaviors—but 17% still slip through, making auto mode unsuitable for high-stakes infrastructure operations. Key design decisions: assistant text and tool results are stripped so the agent can't "talk the classifier into a bad call"; two-stage classification (fast yes/no filter → chain-of-thought reasoning) keeps costs low.

**中文：**
Claude Code 的 auto mode 解决了一个核心矛盾：过于热情的 Agent 可能删除分支、暴露凭证或操作生产数据库。解决方案是双层防御。输入层使用 prompt-injection probe，在内容进入上下文前扫描工具输出，标记可疑内容并附加警告。输出层使用 transcript classifier（Sonnet 4.6 驱动），在执行前根据阻止规则评估每个操作。内部测试结果：最终 FPR 仅 0.4%，阻止 83% 的 overeager 行为——但仍有 17% 漏过，不适合高风险基础设施操作。关键设计决策：剥离 assistant 文本和工具结果，防止 Agent"说服"分类器做出错误判断；两阶段分类（快速是/否过滤器 → 思维链推理）控制成本。
