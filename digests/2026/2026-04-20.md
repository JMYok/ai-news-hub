### Anthropic Engineering — Quantifying infrastructure noise in agentic coding evals

Anthropic 工程团队发现：Terminal-Bench 2.0 的资源限制配置可以导致高达 6 个百分点的分数差异（p < 0.01）。更宽松的资源策略不仅减少基础设施故障（从 5.8% 降至 0.5%），还让 agent 有余力尝试"重量级方案"——这意味着你以为测的是模型能力，实际上可能测的是硬件配置。结论：评测配置应被视为与模型、温度并列的一级实验变量。

Anthropic's engineering team discovered that resource configuration alone can produce up to 6 percentage points of score variation on Terminal-Bench 2.0 (p < 0.01). More generous resource allocation reduces infrastructure errors from 5.8% to 0.5% and enables agents to try heavyweight approaches they couldn't attempt under strict limits—which means what you think you're measuring is model capability, but you may actually be measuring hardware configuration. Recommendation: eval configuration should be treated as a first-class experimental variable, on par with model choice and temperature.

### Anthropic Engineering — Claude Code auto mode: a safer way to skip permissions

Anthropic 发布 Claude Code Auto Mode：用基于模型的分类器替代人工审批，作为"完全跳过权限"和"每个操作都审批"之间的中间地带。Auto Mode 采用双层防御：输入层扫描提示注入，输出层用 Sonnet 4.6 分类器评估每个操作。对真实流量测试：误报率仅 0.4%，对真实过度行为（overeager actions）的漏检率为 17%。

Anthropic published Claude Code Auto Mode: a model-based classifier replaces manual approval, sitting between "skip all permissions" and "approve every action." Auto Mode uses two layers of defense: an input-layer prompt injection probe and an output-layer Sonnet 4.6 transcript classifier evaluating every action. On real traffic: 0.4% false positive rate, 17% false negative rate on real overeager actions.
