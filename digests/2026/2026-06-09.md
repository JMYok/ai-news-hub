### Claude Blog — New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration

Claude 推出 Managed Agents 三项重大更新：

**Dreaming（研究预览）** — 定期回顾 Agent 会话和记忆存储，提取模式、策划记忆，让 Agent 跨会话自我改进。Memory + Dreaming 形成稳健的自改进系统。

**Outcomes** — 写一个描述成功标准的评分标准，Agent 向其努力，独立的 grader 在独立上下文窗口中评估输出，不受 Agent 推理影响。测试中，Outcomes 将任务成功率提升最多 10 个百分点，docx 生成质量 +8.4%，pptx +10.1%。

**Multi-agent orchestration** — 当单个 Agent 做不过来时，lead agent 可以分解任务并委托给专家子 Agent（各自有独立模型、prompt 和工具），并行处理后汇总到 lead agent 的上下文。

客户案例：Harvey 测试中会话完成率提升约6倍；Netflix 平台团队用多 Agent 并行分析数百个构建的日志；Spiral by Every 用 Haiku 做 lead agent、Opus 做撰写子 Agent，并通过 Outcomes 强制执行写作质量标准。

Anthropic's Claude Blog announced three major updates to Managed Agents:

**Dreaming (research preview)** — A scheduled process that reviews agent sessions and memory stores, extracts patterns, and curates memories so agents self-improve between sessions. Memory captures what each agent learns as it works; Dreaming refines that memory between sessions, pulling shared learnings across agents.

**Outcomes** — Write a rubric describing what success looks like; a separate grader evaluates output in its own context window, unaffected by the agent's reasoning. In testing, Outcomes improved task success by up to 10 points, with +8.4% on docx and +10.1% on pptx file generation.

**Multi-agent orchestration** — When there's too much work for a single agent, a lead agent can break the job into pieces and delegate to specialist sub-agents (each with its own model, prompt, and tools) working in parallel on a shared filesystem. Case studies: Harvey saw ~6x improvement in completion rates; Netflix uses it to analyze logs from hundreds of builds in parallel; Spiral by Every uses Haiku as lead agent and Opus for drafting sub-agents.

### The MAD Podcast with Matt Turck — State of Enterprise AI 2026: Aaron Levie on Tokenmaxxing, Rise of Headless, and AI-Proofing Your Job

Box CEO Aaron Levie 是当今对 Agentic AI 思考最深入的 CEO之一——他每天和数十位 CIO 打交道，拥有罕见的横向视角：既身处硅谷工程前线，又运营着全球最大企业之一。

**核心洞察一：AI 企业落地速度被严重高估**
"我们还处于行业的第一天。聊天系统还要再推5年，但同时能力已经延伸到 Agent 了。" 企业刚刚完成聊天机器人的部署，Agent 时代才刚刚开始——但能力已经跳跃到 Agent，这让变革管理变得更难。

**核心洞察二：Token 成本本质是预算归属问题**
从 IT 预算（占收入 3-7%）迁移到业务线预算。好消息是企业不再受 IT 预算约束；坏消息是业务线没有 FinOps 工具、营销团队不知道怎么给计算资源定价。"我们正处于 AI 计算 ERP 的Startup机会——如何决定这些资源被正确使用、如何衡量产生的价值。"

**核心洞察三：代码场景和其他知识工作有根本性差异——差距5-10年**
代码的独特性：可验证（代码要么跑得通要么不通）、上下文在代码库里、工程师有能力纠错。但普通知识工作涉及20个不同系统、数据质量差、权限控制混乱。Agent 会立即遇到权限问题或数据泄露风险。扩散需要数年，不只是几个月。

**核心洞察四：FDE 是长期岗位，不是过渡现象**
"这是非常真实的工作机会，不是你部署完 Agent 就结束了。模型每次升级都有新的集成工作。" 这也解释了为什么 AI 没有消灭就业——Jevons 悖论正在发生：工程师效率提升后，企业愿意接更大的项目，反而需要更多工程师。

**核心洞察五：Headless 软件是必然但不是全部**
数据库查询等场景 headless 占比会远超 GUI；但对于复杂文档操作，GUI 依然更高效。企业在 3 年后将同时拥有座位制和消耗制模型。Box 作为 API-first 公司在 Headless 时代具有天然优势。

Box CEO Aaron Levie has one of the most informed cross-sectional views in enterprise AI—speaking with dozens of CIOs weekly while running one of the world's largest enterprise companies.

Key insight #1: AI enterprise adoption is dramatically slower than the hype suggests. "We're in day one of this as an industry." Enterprises are still rolling out chatbots—and the capability has already jumped to agents, making change management harder, not easier.

Key insight #2: Token cost is really a budget allocation problem. The shift from IT budgets (3-7% of revenue) to line-of-business budgets means enterprises are no longer constrained—but line-of-business has no FinOps tooling. "There's probably a $5B startup waiting to happen just in ERP for your AI compute."

Key insight #3: AI coding and knowledge work have fundamentally different implementation challenges—years apart. Coding is verifiable, context-rich, and engineers can course-correct. Knowledge work spans 20 different systems with poor data quality and messy access controls. Agent deployment will face entitlement issues immediately.

Key insight #4: Internal FDEs are a permanent role, not a过渡 phenomenon. "Once the model changes, there's another set of work to be done." This also explains why AI isn't killing jobs—Jevons paradox is in full effect: as engineers get more productive, companies take on bigger projects, requiring more engineers.

Key insight #5: Headless software is inevitable but not total. Database queries will be overwhelmingly headless; complex document operations still favor GUIs. Enterprises will run a hybrid seat + consumption model. Box, as an API-first company, is naturally positioned for the headless era.

Quote from the episode: "The technology is getting so advanced that it makes obsolete the prior thing that you implemented, which actually means that the rollout takes longer."
