## OFFICIAL BLOGS

**Anthropic Engineering**
**An update on recent Claude Code quality reports**
https://www.anthropic.com/engineering/april-23-postmortem

Anthropic 官方 postmortem：过去一个月 Claude Code 质量下降的完整复盘。三个独立 bug 叠加导致用户感知到"全面退化"：

1. **推理努力默认值从 high 改到 medium**（3月4日，4月7日回滚）：团队为了降低延迟把 Opus 4.6 的默认推理强度从 high 改到 medium，但用户反馈强烈——宁可慢也不要蠢。已恢复为 xhigh。

2. **缓存 bug 导致思维被每轮清除**（3月26日引入，4月10日修复）：一个本意是"空闲超过1小时清除旧思维以节省成本的优化"因为 bug，每轮请求都在清空思维历史，导致 Claude"失忆"、重复、工具调用奇怪。同时导致缓存未命中，消耗量异常增加。

3. **系统 prompt 限制输出长度**（4月16日，4月20日回滚）："文本不超过25词/次，回复不超过100词"这条指令在与其他 prompt 变更组合后，对 Sonnet 4.6/4.7 和 Opus 4.7 的编码质量产生了负面影响——Opus 4.7 做了 ablation 后发现了 3% 的下降。

关键洞察：当用 Opus 4.7 提供完整的代码仓库上下文，它能找到那个 bug——而 Opus 4.6 做不到。Anthropic 把这个发现融入了 Code Review 工具升级。这是一个 AI 辅助调试 AI 自身 bug 的 visceral 实例。

**Anthropic Engineering**
**Scaling Managed Agents: Decoupling the brain from the hands**
https://www.anthropic.com/engineering/managed-agents

Anthropic 讲解 Managed Agents 的架构设计哲学——类比 OS 虚拟化硬件：

核心思路：**把 agent 的各个组件虚拟化**（session = 不可变的append-only事件日志，harness = 调用 Claude 并路由工具调用的循环，sandbox = 代码执行环境），这样每个组件可以独立失败、替换、扩展。

**"宠物 vs 牛"问题**：原来把 session、harness、sandbox 全放在一个容器里，容器挂了 = session 丢了 = 必须恢复。解决方案：让 harness 离开容器，变成 cattle。如果容器挂了，harness 捕获工具调用错误并让 Claude 重试——新容器通过 `execute()` 工具调用按需初始化。

效果：p50 TTFT（首 token 延迟）下降 ~60%，p95 下降 >90%。推理不再需要等容器启动——"many brains"场景下，这个架构意义巨大。

安全边界：原来任何 prompt injection 只需让 Claude 读取自己的环境就能拿到凭证。结构修复：凭证从来不进入 Claude 代码运行的 sandbox，而是通过 vault 外部存储 + MCP proxy 按需获取。

**Claude Blog**
**New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels**
https://claude.com/blog/claude-managed-agents-updates

两项新功能：

- **Self-hosted sandboxes（公开 beta）**：agent 执行环境可以跑在用户自己的基础设施或 Cloudflare/Daytona/Modal/Vercel 上，编排层仍在 Anthropic。文件不离场，凭证不进入 sandbox。

- **MCP tunnels（研究预览）**：连接用户私有网络的 MCP 服务器，无需公网 endpoint，无需 inbound 防火墙规则。客户部署一个轻量 gateway，只做 outbound 连接，在 Claude Platform 和私有服务之间建立加密隧道。

**🔬 Fable Silent Guardrails 引发社区反弹**

**🏭 计算资源的结构性判断**

Rob 和 Ari 都认为计算瓶颈不会在 2027 年前缓解。Rob 提到 ASML 的潜在挑战者：atom lithography（原子光刻，用原子束代替光来打印芯片特征）和 x-ray lithography——两家初创公司已经在这个方向融资。虽然离商业化还有至少五年，但这些是真正的颠覆性技术。
