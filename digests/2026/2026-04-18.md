Notion AI Lead Sarah Sachs: Notion's AI team went through 5 major rebuilds since 2022: first JavaScript APIs → then XML tool calling (didn't work well) → ditched XML for plain Markdown (models adapt better) → finally changed database queries to SQLite syntax (models are extremely good at it). Core lesson: don't impose your data model on the model. Give the model what it wants.

Simon Last, Co-founder & CTO of Notion: The next frontier for agentic AI is the "software factory"—multiple agents collaborating within the same codebase to develop, debug, merge, review, and maintain code. Achieving this requires: 1) a specification layer (using markdown files to describe requirements); 2) self-verification loops (strong testing); 3) agents coordinating via shared Notion databases rather than tight coupling. This is Notion's wildest current exploration direction.

### Anthropic Engineering: Scaling Managed Agents — Decoupling the brain from the hands

Anthropic 工程博客详细解释了托管 Agent 的核心架构设计：把 session（事件日志）、harness（调用循环）、sandbox（执行环境）三层完全解耦。每层都能独立失败和重启，不丢状态。这种设计受到了操作系统虚拟化硬件思路的启发——read() 命令不关心访问的是 1970 年的磁盘还是现代 SSD，接口不变，实现可以随时替换。

核心成果：解耦后 p50 TTFT 下降约 60%，p95 下降超 90%。不再需要"养宠物"（维护状态）；每个组件都能成为"牲口"（可替换）。

---

Anthropic Engineering: Scaling Managed Agents — Decoupling the brain from the hands

Anthropic's engineering blog details the core architecture of Managed Agents: completely decoupling the session (event log), harness (call loop), and sandbox (execution environment). Each layer can fail and restart independently without losing state. This design was inspired by how operating systems virtualized hardware—read() doesn't care whether it's accessing a disk pack from the 1970s or a modern SSD; the interface stays stable while implementations change freely.

Key results: after decoupling, p50 TTFT dropped ~60% and p95 dropped over 90%. No more "pets" to maintain; every component becomes "cattle" (replaceable).

https://www.anthropic.com/engineering/managed-agents
