### Anthropic Engineering — How We Contain Claude Across Products

Anthropic 首次系统披露其三大 Agent 产品的安全架构：claude.ai 的临时容器、Claude Code 的人机协作沙盒，以及 Claude Cowork 的本地虚拟机。三条核心原则：
1. **环境层containment优先于模型层行为引导**——"当概率防御全部漏检时，确定性边界是最后的防线"
2. **隔离强度匹配用户监督能力**——能读懂 bash 的开发者 vs. 不懂命令行的知识工作者，需要不同的安全策略
3. **警惕自建组件**——经过实战检验的 hypervisor、seccomp、gVisor 表现稳健，而自定义 allowlist 代理才是出过问题的薄弱环节

Anthropic's first systematic disclosure of security architecture across three agent products: claude.ai's ephemeral container, Claude Code's human-in-the-loop sandbox, and Claude Cowork's local VM. Three core principles: environment-level containment first, then model-level steering; match isolation strength to user oversight capacity; be wary of custom components.
