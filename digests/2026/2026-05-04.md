### Anthropic Engineering — Scaling Managed Agents: Decoupling the Brain from the Hands

**English:**
Anthropic publishes a deep dive on the architecture behind Claude Managed Agents. The core insight: treat the harness (the loop that calls Claude), the sandbox (where code runs), and the session (the event log) as independent interfaces — decoupled so each can fail and recover without taking down the others. This mirrors how operating systems virtualized hardware into stable abstractions (process, file) that outlasted the hardware itself. Key architectural moves: the harness runs outside the container (making containers "cattle not pets"), auth tokens are never reachable from the sandbox (fixing prompt injection at the structural level), and the session log serves as a context object outside Claude's context window. Result: p50 TTFT dropped ~60%, p95 dropped >90%.

**中文:**
Anthropic 发布了一篇深度解析，阐述 Claude Managed Agents 的架构核心：把 harness（调用 Claude 的循环）、sandbox（代码运行环境）和 session（事件日志）作为独立接口解耦——各自可以独立失败和恢复，互不影响。这与操作系统将硬件虚拟化为稳定抽象（process、file）的思路如出一辙。关键架构决策：harness 运行在容器外部（让容器成为"cattle"而非"pets"）、认证 token 在结构上永远无法从 sandbox 触及（从根本解决 prompt injection）、session 日志作为上下文对象存在于 Claude context window 之外。结果：p50 TTFT 下降约60%，p95 下降超过90%。

https://www.anthropic.com/engineering/managed-agents

### Training Data — OpenAI's Greg Brockman: Why Human Attention Is the New Bottleneck

**English:**
Greg Brockman joined "Training Data" for a wide-ranging conversation. He revealed OpenAI's business is "buy, rent, build compute, resell at margin" — and they're still hunting for more GPUs, admitting "we definitely don't have enough." On scaling laws: "neural networks were designed in the 1940s, before computers — somehow we've taken those exact ideas and as you pour more compute in, models get correspondingly more capable. It just keeps going. There's no wall." He shared a striking internal example: an engineer handed GPT-5.5 a systems optimization spec, went to sleep, and woke up to find the model had autonomously instrumented, profiled, iterated, and delivered the final optimized result. His advice to startups: lean into AI agents now — "we went from agents writing 20% of your code to writing 80%," and this is happening across all computer work this year. On company structure: the cost of building a prototype is now "so cheap" that the bottleneck shifts to sharing and governance. He expects science to see a "real renaissance" — OpenAI already has a physics result where the AI produced a formula that experts thought was unsolvable.

**中文:**
Greg Brockman 接受"Training Data"播客采访，进行了一场深度对话。他透露 OpenAI 的商业模式就是"购买、租赁、建设算力，转售赚取差价"——而他们仍在疯狂寻找更多 GPU，承认"我们肯定不够"。关于 scaling laws："神经网络诞生于1940年代，早于计算机——我们用完全相同的想法，随着投入更多算力，模型能力相应提升。就这样一直继续，没有墙。"他分享了一个令人印象深刻的内部案例：一位工程师把系统优化规格书交给 GPT-5.5，去睡觉，醒来时发现模型已经自主完成了检测、性能分析、迭代并交付了最终优化结果。他对创业者的建议是：现在就要全力拥抱 AI agent——"我们从 agent 写20%的代码变成了写80%"，而且这正在今年所有计算机工作中发生。关于公司结构：构建原型的成本现在"如此便宜"，瓶颈转移到了共享和治理。他预期科学领域将迎来"真正的复兴"——OpenAI 已经有一个物理成果，AI 推导出了一个专家认定无解的公式。
