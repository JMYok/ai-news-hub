### Ryo Lu · Cursor AI 设计负责人

Ryo Lu (Cursor AI) 从一个 2005 年的 Mac 感受出发，写下了他关于 AI 与软件灵魂的思考：那时候软件有质感、有哲学、有个性——即使不必要，也让人感觉有人在在乎。Web 2.0 的个人站点、博客、论坛都是如此。然后我们用 A/B 测试磨平了棱角，用设计系统标准化了性格，用增长换掉了灵魂。

Now every app looks the same. Every interface follows the same patterns. Every product speaks in the same calm, frictionless voice. The humanity got rounded off.

然后 AI Agent 来了，速度变得不可思议——一下午生成一个产品，午饭前发布功能，咖啡还没喝完已经做了十个版本。从想法到代码的 gap 基本上是零。

这听起来难以置信，确实也是。但有一个问题：当 making things 太容易，slop 也随之免费到来。平庸的东西看起来不坏——它们看起来没问题，能 work，能 ship，能 pass review，然后现在有了无限多的它们。互联网正在被功能正常但毫无意义的软件填满。

真正的威胁不是 AI 会取代在乎的人，而是 AI 会淹没他们。最好的东西是由那些无法自拔的人做出来的——为图标失眠的人，把同一行文案改了十二遍的人，因为觉得对了所以加了一个没人要求的动画的人。这种 obsession 不是低效，那是全部意义所在。Taste 无法被量化，Caring 不是参数。那些奇怪、具体、属于"灵魂"的东西，无法被编程出来。

AI 并不会让这些过时。它实际上让这些变得更稀缺、更值钱。正确的路径不是更快地制造更多 slop，而是终于给有真正 vision 的人工具，来制作他们一直想象但无法独自构建的东西。如果做对了，我们得到的不是一个更快的工厂，而是一场文艺复兴。

### Andrej Karpathy · AI 研究员（前 Tesla AI 总监、OpenAI 创始团队成员）

npm axios 遭遇新一轮供应链攻击——axios 是最流行的 HTTP 客户端库，每周下载量达 300M 次。Karpathy 扫描自己的系统，发现几天前实验 gmail/gcal cli 时导入的 `googleworkspace/cli` 包正好落在受影响版本范围（幸好系统安装的是未受影响的 1.13.5 版本）。关键问题是项目依赖未固定——如果中招时间早一天，代码就会解析到最新版本而被植入恶意代码。

Karpathy 认为，**包管理工具（pip、npm 等）的默认设置必须改变**——不能让一次感染（通常因安全扫描而短暂存在）通过未固定依赖自动扩散到所有用户。目前个人可以通过设置 release-age 约束或使用容器来部分防御，但这不是根本解决方案。

A new supply chain attack hit npm axios — the most popular HTTP client library with 300M weekly downloads. Scanning his system, Karpathy found a use of `googleworkspace/cli` that had resolved to an unaffected version (1.13.5) on his machine, but the project dependency was unpinned — meaning had he done it earlier that day, the code would have resolved to latest and he'd have been pwned. Package managers' defaults have to change so that a single infection doesn't spread through users at random and at scale via unpinned dependencies.

### Aaron Levie · Box CEO

Levie 发文阐述 Agent 自动化知识工作的工作量本质：设置非结构化数据让 Agent 轻松访问、学习工作流程和流程并创建 Agent 可利用的技能或计划、连接不同系统、可能还需要改变流程本身以支持 Agent 工作——然后设计人类在 workflow 中的角色、如何验证工作等。没有捷径，这些必须由团队中的人来完成。

这和编程不同——编程的收益不需要这种程度的工作，因为 Agent 更容易获得上下文，用户也更技术化。但对于其他知识工作，没有任何办法绕过这些。他说：**企业内将出现大量新岗位，专门做这件事的人将在经济中获得巨大价值，是早期职业者快速产生影响的好方向。**

There's a huge opportunity for entrepreneurial talent within organizations to reimagine workflows for a world of agents. Automating work with agents requires real work: setting up unstructured data so agents can access it, learning workflows and creating skills/plans for agents to leverage, connecting disparate systems, and likely changing the process itself. Most gains from coding don't take this level of effort because the agent knows more and users are technical. But for the rest of knowledge work, there's no way around it — it has to be done by people. You'll see huge growth of roles within enterprises, and people who specialize in this will be hugely valuable in the economy. Great way for early career folks to make a huge dent quickly.
